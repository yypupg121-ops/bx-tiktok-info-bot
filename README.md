# BX TikTok Info

بوت تيليجرام لعرض المعلومات التي يعيدها مصدر TikTok API الموجود في المشروع. يحافظ على الاشتراك الإجباري بقناة `@bxcode`، ويدعم البحث من المحادثة وMini App، وصورة الحساب عند توفرها، وملف TXT، وسجل بحث ومفضلات محفوظة في SQLite.

## المتطلبات والتشغيل

- Python 3.10 أو أحدث.
- بوت تيليجرام من [@BotFather](https://t.me/BotFather).
- أضف البوت إلى قناة الاشتراك وامنحه صلاحية التحقق من حالة الأعضاء.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
export BOT_TOKEN='رمز البوت'
python bot.py
```

لا ترفع `BOT_TOKEN` إلى GitHub. يمكن ضبط الإعدادات التالية كمتغيرات بيئة:

- `BOT_TOKEN`: رمز البوت، مطلوب.
- `REQUIRED_CHANNEL`: قناة الاشتراك، افتراضياً `@bxcode`.
- `CHANNEL_URL`: رابط القناة، افتراضياً `https://t.me/bxcode`.
- `TIKTOK_API_URL`: نقطة API الحالية في المشروع؛ القيمة الافتراضية لم تتغير.
- `DATABASE_PATH`: ملف SQLite، افتراضياً `bx_tiktok.sqlite3`.
- `MINI_APP_URL`: رابط HTTPS اختياري لواجهة Mini App.
- `LOG_LEVEL`: مستوى السجل، افتراضياً `INFO`.

## الوظائف

- زر **🔎 بحث** يطلب اليوزر ثم يعرض بيانات API بترتيب مختصر، ويُحدّث رسالة البوت نفسها متى أمكن.
- نتيجة البحث تحتفظ بصورة الحساب عند توفرها، وتُرفق ملف معلومات UTF-8 باسم `BX@BXCODE.txt`.
- البحث الناجح فقط يزيد عداد المستخدم وسجل بحثه. التحديث وفتح الحساب من المفضلة لا يحسبان بحثاً جديداً.
- **🔴 إحصائياتي** تعرض عدد البحوث والمفضلات وآخر عشرة حسابات بحث عنها المستخدم.
- **⭐ المفضلة** تعرض حسابات المستخدم وأسماءها المتاحة، وتدعم الإضافة والحذف مع تأكيد قبل الحذف.
- بيانات المستخدمين منفصلة بحسب Telegram user ID ومخزنة في SQLite لتبقى بعد إعادة تشغيل البوت. `/delete_me` يحذف بيانات صاحب الأمر فقط.
- `/start` يعرض القائمة. `/help` يعرض شرح الاستخدام. `/privacy` يوضح التخزين.
- إذا أُعدّ `MINI_APP_URL`، يبقى زر Mini App وزر القائمة الخاص به متاحين.
- يستخدم زر الإحصائيات `style="danger"` عندما تقبله نسخة aiogram وواجهة Bot API. قد يختلف عرض اللون بحسب نسخة تطبيق تيليجرام.

## تشغيل Mini App

ارفع محتويات `miniapp/` إلى استضافة HTTPS، ثم عيّن `MINI_APP_URL` إلى رابط الصفحة وأعد تشغيل البوت. الواجهة ترسل اليوزر فقط؛ ويتحقق البوت من صيغة الاسم والاشتراك قبل البحث.
