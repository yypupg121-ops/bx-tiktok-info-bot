# BX TikTok Info — النسخة المطورة

نسخة عربية مطورة من بوت فحص المعلومات العامة لحسابات TikTok. تتضمن البحث بالرسائل وMini App، تقارير TXT، المفضلة، سجلًا وإحصائيات للمستخدم، اشتراكًا إجباريًا قابلًا للضبط، وحدًا زمنيًا بسيطًا لتقليل الإغراق.

> تنبيه: البوت لا يتصل بحسابات TikTok ولا يطلب كلمات مرور. النتائج تأتي من API خارجي غير تابع رسميًا لتيك توك، وقد تكون غير دقيقة أو تتوقف. استخدم البيانات العامة بمسؤولية.

## المتطلبات

- Python 3.10 أو أحدث.
- بوت أنشأته عبر [@BotFather](https://t.me/BotFather).
- قناة الاشتراك التي يستطيع البوت التحقق منها (أضف البوت مشرفًا أو امنحه صلاحية رؤية الأعضاء).
- استضافة HTTPS لملف `miniapp/index.html` حتى تظهر ميزة Mini App. لا تضع رمز البوت في الموقع.

## التشغيل

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

ضع القيم في متغيرات البيئة، ولا ترفع الرمز إلى مستودع عام:

```bash
export BOT_TOKEN='رمز البوت'
export REQUIRED_CHANNEL='@اسم_القناة'
export CHANNEL_URL='https://t.me/اسم_القناة'
export MINI_APP_URL='https://example.com/'
python bot.py
```

على Termux يمكن تثبيت Python عبر `pkg install python` ثم تثبيت المتطلبات بالطريقة نفسها. استخدم جلسة `tmux` أو مدير عمليات مناسب لإبقائه عاملًا.

## نشر Mini App

ارفع محتويات مجلد `miniapp/` إلى خدمة استضافة صفحات ثابتة تدعم HTTPS، ثم ضع رابط الصفحة الكامل في `MINI_APP_URL` وأعد تشغيل البوت. عندها يضيف البوت زر Mini App ويضبط زر القائمة. يمكن أيضًا ضبط Main Mini App من BotFather. الواجهة ترسل اسم المستخدم فقط عبر `Telegram.WebApp.sendData`؛ البوت يعيد التحقق من الصيغة والاشتراك قبل تنفيذ البحث.

## ميزات المستخدم

- `/start` القائمة الرئيسية، `/help` المساعدة، `/privacy` الخصوصية، `/delete_me` حذف سجل المستخدم والمفضلة.
- إرسال اسم مستخدم مباشرة أو الاختيار من القائمة.
- صورة الحساب عند توفرها، ملخص منسق، وملف TXT.
- حفظ/إزالة المفضلة وعرض آخر 20 حسابًا.
- عداد عمليات الفحص، SQLite مع WAL، حماية بسيطة من النقر/الطلب المتكرر.
- التحقق من الاشتراك قبل الخدمات، وواجهة فشل مفهومة عند تعطل API.
- أزرار بألوان `primary` و`success` متى دعمتها نسخة Bot API وتطبيق تيليجرام؛ في العملاء الأقدم قد تظهر الأزرار بالشكل المعتاد. لا يستطيع البوت اختيار ألوان حرة أو فرضها على كل نسخ تيليجرام.

## الإعدادات

- `BOT_TOKEN`: مطلوب.
- `REQUIRED_CHANNEL`: معرّف/اسم قناة الاشتراك، الافتراضي `@bxcode`.
- `CHANNEL_URL`: رابط القناة.
- `MINI_APP_URL`: رابط HTTPS للـ Mini App؛ اتركه فارغًا لتعطيل زر Mini App.
- `TIKTOK_API_URL`: نقطة API الخارجية الحالية.
- `DATABASE_PATH`: مسار قاعدة SQLite، الافتراضي `bx_tiktok.sqlite3`.
- `LOG_LEVEL`: مستوى السجلات، الافتراضي `INFO`.

## ملاحظات تشغيلية

1. لا تشارك `BOT_TOKEN` أو تضعه في ملفات الويب أو Git. إذا سبق نشر الرمز، ألغِه من BotFather وأصدر آخر.
2. قاعدة SQLite تخزن معرف تيليجرام واسم المستخدم واسم الحساب وعدد البحث والمفضلة. `/delete_me` يحذف سجل هذا المستخدم.
3. اشتراك القناة يكون أقل موثوقية إذا لم يتمكن البوت من الوصول إلى حالة العضو؛ راجع صلاحيات البوت واسم القناة عند ظهور تعذر التحقق.
4. لا توجد ألوان حرة لزر inline ولا يمكن ضمان ظهور تلوين الأزرار في العملاء القديمة؛ نمط الزر الرسمي اختياري ومدعوم حسب تحديث Bot API/Telegram.
5. API المستخدم موروث من النسخة الأصلية، لذا يُنصح بمراجعته واستبداله بمصدر موثوق/مرخص إن كان الاستخدام إنتاجيًا.
